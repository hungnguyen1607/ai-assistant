# Exercises 2.4 — Problems 1–5

Determine whether the equation is exact. If it is exact, solve it.

Recipe: M dx + N dy = 0 → check M_y = N_x → f = ∫M dx + g(y) → set f_y = N, solve for g → answer f(x, y) = c.

---

## Problem 1 — (2x − 1) dx + (3y + 7) dy = 0

```
M = 2x − 1
N = 3y + 7

Exactness test:
  M_y = ∂/∂y (2x − 1) = 0
  N_x = ∂/∂x (3y + 7) = 0
  M_y = N_x  → EXACT

Integrate M with respect to x (y held constant):
  f = ∫ (2x − 1) dx
  f = x² − x + g(y)

Differentiate with respect to y, set equal to N:
  f_y = 0 − 0 + g′(y)
  g′(y) = 3y + 7

Integrate:
  g(y) = (3/2)y² + 7y

f = x² − x + (3/2)y² + 7y
```

**Answer: x² − x + (3/2)y² + 7y = c**

Check: f_x = 2x − 1 = M ✓  f_y = 3y + 7 = N ✓

## Problem 2 — (2x + y) dx − (x + 6y) dy = 0

```
Careful with the minus sign — it belongs to N:
  M = 2x + y
  N = −(x + 6y) = −x − 6y

Exactness test:
  M_y = ∂/∂y (2x + y) = 1
  N_x = ∂/∂x (−x − 6y) = −1
  1 ≠ −1  → NOT EXACT
```

**Answer: Not exact.** (The problem only asks you to solve it if it's exact, so stop here.)

## Problem 3 — (5x + 4y) dx + (4x − 8y³) dy = 0

```
M = 5x + 4y
N = 4x − 8y³

Exactness test:
  M_y = ∂/∂y (5x + 4y) = 4
  N_x = ∂/∂x (4x − 8y³) = 4
  M_y = N_x  → EXACT

Integrate M with respect to x (y held constant):
  f = ∫ (5x + 4y) dx
  f = (5/2)x² + 4xy + g(y)

Differentiate with respect to y, set equal to N:
  f_y = 0 + 4x + g′(y)
  4x + g′(y) = 4x − 8y³
  g′(y) = −8y³

Integrate:
  g(y) = −8y⁴/4 = −2y⁴

f = (5/2)x² + 4xy − 2y⁴
```

**Answer: (5/2)x² + 4xy − 2y⁴ = c**

Check: f_x = 5x + 4y = M ✓  f_y = 4x − 8y³ = N ✓

## Problem 4 — (sin y − y sin x) dx + (cos x + x cos y − y) dy = 0

```
M = sin y − y sin x
N = cos x + x cos y − y

Exactness test:
  M_y = ∂/∂y (sin y − y sin x) = cos y − sin x
  N_x = ∂/∂x (cos x + x cos y − y) = −sin x + cos y
  M_y = N_x  → EXACT

Integrate M with respect to x (y held constant):
  f = ∫ (sin y − y sin x) dx
    = x sin y − y ∫ sin x dx
    = x sin y − y(−cos x)
  f = x sin y + y cos x + g(y)

Differentiate with respect to y, set equal to N:
  f_y = x cos y + cos x + g′(y)
  x cos y + cos x + g′(y) = cos x + x cos y − y
  g′(y) = −y

Integrate:
  g(y) = −y²/2

f = x sin y + y cos x − y²/2
```

**Answer: x sin y + y cos x − (1/2)y² = c**

Check: f_x = sin y − y sin x = M ✓  f_y = x cos y + cos x − y = N ✓

## Problem 5 — (2xy² − 3) dx + (2x²y + 4) dy = 0

```
M = 2xy² − 3
N = 2x²y + 4

Exactness test:
  M_y = ∂/∂y (2xy² − 3) = 4xy
  N_x = ∂/∂x (2x²y + 4) = 4xy
  M_y = N_x  → EXACT

Integrate M with respect to x (y held constant):
  f = ∫ (2xy² − 3) dx
  f = x²y² − 3x + g(y)

Differentiate with respect to y, set equal to N:
  f_y = 2x²y + g′(y)
  2x²y + g′(y) = 2x²y + 4
  g′(y) = 4

Integrate:
  g(y) = 4y

f = x²y² − 3x + 4y
```

**Answer: x²y² − 3x + 4y = c**

Check: f_x = 2xy² − 3 = M ✓  f_y = 2x²y + 4 = N ✓
