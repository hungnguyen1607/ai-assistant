# Exercises 2.2 — Problems 1–5

Solve by separation of variables: get all y's with dy, all x's with dx, then integrate both sides.

---

## Problem 1 — dy/dx = sin 5x

```
dy/dx = sin 5x

Separate:
  dy = sin 5x dx

Integrate both sides:
  ∫ dy = ∫ sin 5x dx

Right side, sub u = 5x, du = 5 dx → dx = du/5:
  ∫ sin 5x dx = (1/5) ∫ sin u du
              = (1/5)(−cos u)
              = −(1/5) cos 5x

y = −(1/5) cos 5x + c
```

**Answer: y = −(1/5) cos 5x + c**

Check: y′ = −(1/5)(−sin 5x)(5) = sin 5x ✓

## Problem 2 — dy/dx = (x + 1)²

```
dy/dx = (x + 1)²

Separate:
  dy = (x + 1)² dx

Integrate both sides:
  ∫ dy = ∫ (x + 1)² dx

Right side, sub u = x + 1, du = dx:
  ∫ u² du = u³/3 = (x + 1)³/3

y = (x + 1)³/3 + c
```

**Answer: y = (1/3)(x + 1)³ + c**

Check: y′ = (1/3)·3(x + 1)²·1 = (x + 1)² ✓

## Problem 3 — dx + e^(3x) dy = 0

```
dx + e^(3x) dy = 0

Move dx over:
  e^(3x) dy = −dx

Divide by e^(3x):
  dy = −e^(−3x) dx

Integrate both sides:
  ∫ dy = −∫ e^(−3x) dx

Right side:
  ∫ e^(−3x) dx = e^(−3x)/(−3) = −(1/3)e^(−3x)
  so −∫ e^(−3x) dx = (1/3)e^(−3x)

y = (1/3)e^(−3x) + c
```

**Answer: y = (1/3)e^(−3x) + c**

Check: dy = −e^(−3x) dx
 dx + e^(3x)(−e^(−3x) dx) = dx − dx = 0 ✓

## Problem 4 — dy − (y − 1)² dx = 0

```
dy − (y − 1)² dx = 0

Move the dx term over:
  dy = (y − 1)² dx

Divide by (y − 1)²:
  dy/(y − 1)² = dx

Integrate both sides:
  ∫ (y − 1)^(−2) dy = ∫ dx

Left side, sub u = y − 1, du = dy:
  ∫ u^(−2) du = u^(−1)/(−1) = −1/(y − 1)

  −1/(y − 1) = x + c

Solve for y:
  1/(y − 1) = −(x + c)
  y − 1 = −1/(x + c)
  y = 1 − 1/(x + c)
```

**Answer: y = 1 − 1/(x + c)**

Note: we divided by (y − 1)², which assumes y ≠ 1. y = 1 is also a solution (dy = 0, (1 − 1)² = 0) that the family misses.

Check: y′ = 1/(x + c)²
 (y − 1)² = (−1/(x + c))² = 1/(x + c)² ✓ equal

## Problem 5 — x dy/dx = 4y

```
x dy/dx = 4y

Separate (divide by xy, multiply by dx):
  dy/y = 4 dx/x

Integrate both sides:
  ∫ dy/y = 4 ∫ dx/x
  ln|y| = 4 ln|x| + c₁

Log rule 4 ln|x| = ln(x⁴):
  ln|y| = ln(x⁴) + c₁

Exponentiate both sides:
  |y| = e^(ln x⁴ + c₁)
  |y| = e^(c₁) · x⁴
  y = ±e^(c₁) · x⁴

Rename ±e^(c₁) = c:
  y = c x⁴
```

**Answer: y = cx⁴**

(c = 0 gives y = 0, which is also a solution, so nothing is lost.)

Check: y′ = 4cx³
 x·y′ = x·4cx³ = 4cx⁴ = 4y ✓

## Problem 6 — dy/dx + 2xy² = 0

```
dy/dx + 2xy² = 0

Move the 2xy² over:
  dy/dx = −2xy²

Separate: divide by y², multiply by dx:
  dy/y² = −2x dx

Write 1/y² as y^(−2):
  y^(−2) dy = −2x dx

Integrate both sides:
  ∫ y^(−2) dy = ∫ −2x dx

Left side (power rule): ∫ y^(−2) dy = y^(−1)/(−1) = −1/y
Right side: ∫ −2x dx = −x²
  −1/y = −x² + c₁

Multiply both sides by −1:
  1/y = x² − c₁

Rename the constant −c₁ = c:
  1/y = x² + c

Flip both sides:
  y = 1/(x² + c)
```

**Answer: y = 1/(x² + c)**

Note: we divided by y², which assumes y ≠ 0. y = 0 is also a solution (dy = 0 and 2xy² = 0) that this family misses — the "singular solution".

Check: y = (x² + c)^(−1) → y′ = −(x² + c)^(−2)·2x = −2x/(x² + c)²
 2xy² = 2x·(1/(x² + c))² = 2x/(x² + c)²
 y′ + 2xy² = −2x/(x² + c)² + 2x/(x² + c)² = 0 ✓
(SymPy: verified)

## Problem 7 — dy/dx = e^(3x+2y)

```
dy/dx = e^(3x+2y)

Split the exponent with the rule e^(a+b) = e^a·e^b:
  dy/dx = e^(3x)·e^(2y)

Separate: divide by e^(2y), multiply by dx:
  dy/e^(2y) = e^(3x) dx

Write 1/e^(2y) as e^(−2y):
  e^(−2y) dy = e^(3x) dx

Integrate both sides:
  ∫ e^(−2y) dy = ∫ e^(3x) dx

Left side: ∫ e^(−2y) dy = e^(−2y)/(−2) = −(1/2)e^(−2y)
Right side: ∫ e^(3x) dx = (1/3)e^(3x)

  −(1/2)e^(−2y) = (1/3)e^(3x) + c₁

Multiply both sides by −2:
  e^(−2y) = −(2/3)e^(3x) − 2c₁

Rename the constant −2c₁ = c:
  e^(−2y) = c − (2/3)e^(3x)

Take ln of both sides:
  −2y = ln(c − (2/3)e^(3x))

Divide by −2:
  y = −(1/2) ln(c − (2/3)e^(3x))
```

**Answer: y = −(1/2) ln(c − (2/3)e^(3x))**

Check: y′ = −(1/2)·(1/(c − (2/3)e^(3x)))·(−(2/3)·3e^(3x)) = (1/2)·(2e^(3x))/(c − (2/3)e^(3x))
        = e^(3x)/(c − (2/3)e^(3x))
 And e^(3x+2y) = e^(3x)·e^(2y) = e^(3x)·e^(ln(c − (2/3)e^(3x))^(−1)) = e^(3x)·(c − (2/3)e^(3x))^(−1) ✓
(SymPy: verified)

### Pattern: "separable, y stuck in an exponent"

How to recognize it: y appears multiplied by itself (y²) or inside an e^(...) — so the equation
is a product g(x)·f(y), each variable cleanly on one side.

Steps:
1. Split any e^(a+b) into e^a·e^b.
2. Rearrange to f(y) dy = g(x) dx (divide by f(y), move dx over).
3. Integrate both sides; handle y^(−2) with the power rule, e^(−2y) with e^u/coeff.
4. Solve for y if you can (logs when y is in an exponent).

The trap: dividing by y² (or any f(y)) secretly kills y-values that make f(y) = 0 — check if those are also solutions.

## Problem 8 — e^x·y·dy/dx = e^(-y) + e^(-2x-y)

In Problems 1–22, solve the given differential equation by separation of variables.
8. $$ e^x y\frac{dy}{dx} = e^{-y} + e^{-2x-y} $$

Type: first order, separable.

Right side factors: e^(-y) + e^(-2x-y) = e^(-y)(1 + e^(-2x)).

So:
```
e^x*y*dy/dx = e^(-y)(1 + e^(-2x))

Divide both sides by e^x:
y*dy/dx = e^(-y)(1 + e^(-2x)) / e^x = e^(-y)(e^(-x) + e^(-3x))

Separate (multiply by e^y dx):
y*e^y dy = (e^(-x) + e^(-3x)) dx
```

Integrate both sides.

Left: use integration by parts with u = y, dv = e^y dy, so du = dy, v = e^y.
∫ y e^y dy = y e^y - ∫ e^y dy = y e^y - e^y.

Right: ∫ e^(-x) dx = -e^(-x);  ∫ e^(-3x) dx = -(1/3)e^(-3x).

```
y*e^y - e^y = -e^(-x) - (1/3)e^(-3x) + C
```

(No ln| | trouble here; the equation is implicit in y.)

**Answer:** y·e^y − e^y = −e^(−x) − (1/3)e^(−3x) + C   (implicit general solution)

Check: differentiate implicitly.
d/dx [y e^y - e^y] = y' e^y + y y' e^y - y' e^y = y y' e^y.
d/dx [-e^(-x) - (1/3)e^(-3x)] = e^(-x) + e^(-3x).
So y y' e^y = e^(-x) + e^(-3x)  →  y' = (e^(-x) + e^(-3x)) / (y e^y).
And the ODE gives y' = e^(-y)(1+e^(-2x)) / (e^x y) = (e^(-x) + e^(-3x))/(y e^y). ✓

## Problem 9 — y·ln x·dx/dy = ((y+1)/x)²

In Problems 1–22, solve the given differential equation by separation of variables.
9. $$ y \ln x \frac{dx}{dy} = \left(\frac{y + 1}{x}\right)^2 $$

Type: first order, separable. Treat x as the function of y.

```
y*ln(x)*dx/dy = (y+1)^2 / x^2

Multiply both sides by x^2 / (y*ln(x)):
x^2 dx = (y+1)^2 / (y*ln(x)) ... 
```

Better: separate so each side has one variable:
```
x^2 dx / (ln x)?? no -- keep ln x with x:
```
Rewrite:
```
y*ln(x)*dx/dy = (y+1)^2/x^2
→ x^2 ln(x) dx = ((y+1)^2 / y) dy
```
Wait: multiply both sides by x^2 dy:
x^2 * y * ln(x) dx = (y+1)^2 dy
→ x^2 ln(x) dx = [(y+1)^2 / y] dy.

Right side simplify: (y+1)^2 / y = (y^2 + 2y + 1)/y = y + 2 + 1/y.

Integrate right: ∫(y + 2 + 1/y) dy = y^2/2 + 2y + ln|y|.

Integrate left: ∫ x^2 ln(x) dx. Use integration by parts: u = ln x, dv = x^2 dx, du = dx/x, v = x^3/3.
∫ x^2 ln x dx = (x^3/3) ln x - ∫ (x^3/3)(1/x) dx = (x^3/3) ln x - (1/3)∫ x^2 dx
= (x^3/3) ln x - x^3/9.

So:
```
(x^3/3) ln x - x^3/9 = y^2/2 + 2y + ln|y| + C
```

**Answer:** (x³/3)·ln x − x³/9 = y²/2 + 2y + ln|y| + C   (implicit general solution)

Check: differentiate both sides w.r.t. y (x = x(y)).
d/dy[(x^3/3)ln x - x^3/9] = (x^2 ln x + x^2/3 - x^2/3) x' = x^2 ln x · x'.
d/dy[y^2/2 + 2y + ln|y|] = y + 2 + 1/y = (y+1)^2/y.
So x^2 ln x x' = (y+1)^2/y → x' = (y+1)^2/(y x^2 ln x), which is exactly the original equation solved for dx/dy. ✓
