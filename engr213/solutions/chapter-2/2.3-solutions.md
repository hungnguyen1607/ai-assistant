# Exercises 2.3 — Problems 1–5

Find the general solution, the largest interval, and any transient terms.

Recipe: standard form y′ + P(x)y = f(x) → μ = e^(∫P dx) → (μy)′ = μf → integrate → divide by μ.

---

## Problem 1 — dy/dx = 5y

```
dy/dx = 5y

Standard form (move 5y left):
  y′ − 5y = 0
  P = −5, f = 0

Integrating factor:
  ∫P dx = ∫−5 dx = −5x
  μ = e^(−5x)

Multiply through:
  e^(−5x) y′ − 5e^(−5x) y = 0
  (e^(−5x) y)′ = 0

Integrate:
  e^(−5x) y = c

Divide by e^(−5x):
  y = c e^(5x)
```

**Answer: y = ce^(5x), I = (−∞, ∞)**

Transient: none. ce^(5x) → ∞ as x → ∞ (it grows instead of dying out).

Check: y′ = 5ce^(5x) = 5y ✓

## Problem 2 — dy/dx + 2y = 0

```
y′ + 2y = 0
  P = 2, f = 0

Integrating factor:
  ∫P dx = ∫2 dx = 2x
  μ = e^(2x)

Multiply through:
  e^(2x) y′ + 2e^(2x) y = 0
  (e^(2x) y)′ = 0

Integrate:
  e^(2x) y = c

Divide by e^(2x):
  y = c e^(−2x)
```

**Answer: y = ce^(−2x), I = (−∞, ∞)**

Transient: ce^(−2x) → 0 as x → ∞, so it's transient.

Check: y′ = −2ce^(−2x)
 y′ + 2y = −2ce^(−2x) + 2ce^(−2x) = 0 ✓

## Problem 3 — dy/dx + y = e^(3x)

```
y′ + y = e^(3x)
  P = 1, f = e^(3x)

Integrating factor:
  ∫P dx = ∫1 dx = x
  μ = e^x

Multiply through:
  e^x y′ + e^x y = e^x · e^(3x)
  (e^x y)′ = e^(4x)

Integrate:
  e^x y = ∫ e^(4x) dx
  e^x y = (1/4)e^(4x) + c

Divide by e^x:
  y = (1/4)e^(4x)/e^x + c/e^x
  y = (1/4)e^(3x) + c e^(−x)
```

**Answer: y = (1/4)e^(3x) + ce^(−x), I = (−∞, ∞)**

Transient: ce^(−x) → 0 as x → ∞, so it's transient. (1/4)e^(3x) grows, so it's not.

Check: y′ = (3/4)e^(3x) − ce^(−x)
 y′ + y = (3/4)e^(3x) − ce^(−x) + (1/4)e^(3x) + ce^(−x) = e^(3x) ✓

## Problem 4 — 3 dy/dx + 12y = 4

```
3y′ + 12y = 4

Standard form (divide by 3):
  y′ + 4y = 4/3
  P = 4, f = 4/3

Integrating factor:
  ∫P dx = ∫4 dx = 4x
  μ = e^(4x)

Multiply through:
  e^(4x) y′ + 4e^(4x) y = (4/3)e^(4x)
  (e^(4x) y)′ = (4/3)e^(4x)

Integrate:
  e^(4x) y = (4/3) ∫ e^(4x) dx
  e^(4x) y = (4/3)(1/4)e^(4x) + c
  e^(4x) y = (1/3)e^(4x) + c

Divide by e^(4x):
  y = 1/3 + c e^(−4x)
```

**Answer: y = 1/3 + ce^(−4x), I = (−∞, ∞)**

Transient: ce^(−4x) → 0 as x → ∞, so it's transient. y settles at 1/3.

Check: y′ = −4ce^(−4x)
 3y′ + 12y = −12ce^(−4x) + 4 + 12ce^(−4x) = 4 ✓

## Problem 5 — y′ + 3x²y = x²

```
y′ + 3x²y = x²
  P = 3x², f = x²

Integrating factor:
  ∫P dx = ∫3x² dx = x³
  μ = e^(x³)

Multiply through:
  e^(x³) y′ + 3x² e^(x³) y = x² e^(x³)
  (e^(x³) y)′ = x² e^(x³)

Integrate:
  e^(x³) y = ∫ x² e^(x³) dx

Right side, sub u = x³, du = 3x² dx → x² dx = du/3:
  ∫ x² e^(x³) dx = (1/3) ∫ e^u du
                 = (1/3)e^u
                 = (1/3)e^(x³)

  e^(x³) y = (1/3)e^(x³) + c

Divide by e^(x³):
  y = 1/3 + c e^(−x³)
```

**Answer: y = 1/3 + ce^(−x³), I = (−∞, ∞)**

Transient: ce^(−x³) → 0 as x → ∞, so it's transient.

Check: y′ = −3x²ce^(−x³)
 y′ + 3x²y = −3x²ce^(−x³) + 3x²(1/3) + 3x²ce^(−x³) = x² ✓
