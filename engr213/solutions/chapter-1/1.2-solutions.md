# Exercises 1.2 — Problems 1–5

Problems 1–2: y = 1/(1 + c₁e^(−x)) is a family of solutions of y′ = y − y².
Problems 3–5: y = 1/(x² + c) is a family of solutions of y′ + 2xy² = 0. Give the largest interval I.

---

## Problem 1 — y(0) = −1/3

```
y = 1/(1 + c₁e^(−x))

Plug in x = 0, y = −1/3:
  −1/3 = 1/(1 + c₁e^0)
  −1/3 = 1/(1 + c₁)

Flip both sides:
  1 + c₁ = −3
  c₁ = −3 − 1
  c₁ = −4

y = 1/(1 − 4e^(−x))
```

**Answer: y = 1/(1 − 4e^(−x))**

Check: y(0) = 1/(1 − 4·1) = 1/(−3) = −1/3 ✓

---

## Problem 2 — y(−1) = 2

```
y = 1/(1 + c₁e^(−x))

Plug in x = −1, y = 2:
  2 = 1/(1 + c₁e^(−(−1)))
  2 = 1/(1 + c₁e)

Flip both sides:
  1 + c₁e = 1/2
  c₁e = 1/2 − 1
  c₁e = −1/2
  c₁ = −1/(2e)

y = 1/(1 − (1/(2e))·e^(−x))

Simplify (1/e)·e^(−x) = e^(−x−1):
y = 1/(1 − ½e^(−(x+1)))
```

**Answer: y = 1/(1 − ½e^(−(x+1)))**

Check: y(−1) = 1/(1 − ½e^0) = 1/(1 − ½) = 1/(½) = 2 ✓

---

## Problem 3 — y(2) = 1/3

```
y = 1/(x² + c)

Plug in x = 2, y = 1/3:
  1/3 = 1/(2² + c)
  1/3 = 1/(4 + c)

Flip both sides:
  4 + c = 3
  c = −1

y = 1/(x² − 1)

Interval — denominator = 0:
  x² − 1 = 0
  x² = 1
  x = ±1

Pieces: (−∞, −1), (−1, 1), (1, ∞)
x₀ = 2 is in (1, ∞)
```

**Answer: y = 1/(x² − 1), I = (1, ∞)**

Check: y(2) = 1/(4 − 1) = 1/3 ✓

---

## Problem 4 — y(−2) = 1/2

```
y = 1/(x² + c)

Plug in x = −2, y = 1/2:
  1/2 = 1/((−2)² + c)
  1/2 = 1/(4 + c)

Flip both sides:
  4 + c = 2
  c = −2

y = 1/(x² − 2)

Interval — denominator = 0:
  x² − 2 = 0
  x² = 2
  x = ±√2  (≈ ±1.414)

Pieces: (−∞, −√2), (−√2, √2), (√2, ∞)
x₀ = −2 is in (−∞, −√2)
```

**Answer: y = 1/(x² − 2), I = (−∞, −√2)**

Check: y(−2) = 1/(4 − 2) = 1/2 ✓

---

## Problem 5 — y(0) = 1

```
y = 1/(x² + c)

Plug in x = 0, y = 1:
  1 = 1/(0² + c)
  1 = 1/c
  c = 1

y = 1/(x² + 1)

Interval — denominator = 0:
  x² + 1 = 0
  x² = −1   → no real solution

Denominator is never 0, so no breaks.
```

**Answer: y = 1/(x² + 1), I = (−∞, ∞)**

Check: y(0) = 1/(0 + 1) = 1 ✓
